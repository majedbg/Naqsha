# Bundled fonts — licensing

Every font served from this directory is licensed under the **SIL Open Font
License, Version 1.1** (OFL-1.1). The full license text for each family ships
beside its `.ttf` as `<id>.OFL.txt` (authoritative copyright + any Reserved Font
Name).

The OFL explicitly permits both uses this app relies on:

1. **Bundling** the font files with the application, and
2. **Embedding** each glyph's outline into exported documents — the vectorized
   text in an exported plotter/laser SVG is a permitted *document*, not a
   redistribution of the font software.

The only OFL restrictions that matter here — do **not** sell the font files
standalone, and do **not** reuse a Reserved Font Name on a modified version — are
not triggered by this app's use.

All families were pulled from the [google/fonts](https://github.com/google/fonts)
`ofl/` tree and verified to parse and render cleanly in opentype.js (the exact
parser the text feature uses) before inclusion.
